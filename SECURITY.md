# Security Policy

## Educational Purpose

This repository is intended strictly for:
- cybersecurity education
- ethical hacking practice
- authorized penetration testing
- research and learning environments

## Responsible Usage

Users must:
- obtain proper authorization before testing
- comply with local laws and regulations
- use tools only in permitted environments

## Prohibited Usage

Do NOT use this project for:
- unauthorized access
- malicious attacks
- illegal activities
- credential theft
- harmful payload distribution

## Disclaimer

The maintainer assumes no responsibility for misuse,
damage, or unlawful activities performed using this software.
